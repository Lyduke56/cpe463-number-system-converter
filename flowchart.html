ANSI / ISO 5807 Standard Programming Flowchart Shapes

Standard Geometric Flowchart Symbols

Traditional computer science flowchart shapes explicitly differentiate terminals, user operations, I/O streams, mathematical processes, conditional evaluations, loops, and subroutine calls:

Terminal (Oval / Stadium)
Program startup, termination, function entry, or return.
Manual Input (Trapezoid)
Human user interaction: clicking buttons, selecting options, typing.
Data I/O (Parallelogram)
Reading data values from input fields or displaying calculated outputs.
Process (Rectangle)
Internal computation, data assignment, and arithmetic calculation.
Decision (Diamond)
Conditional branch (IF / SWITCH) yielding True/False or Yes/No paths.
Preparation (Hexagon)
Loop control, index initialization, and iteration counters.
Predefined Process
Calling modular sub-functions (e.g. ParseToDecimal, FormatBase).

2. Core Calculation Engine (`ProcessCalculation`)

The primary 4-phase algorithm with validation, per-row multi-base matrices, sequential chain arithmetic, and final conversions.

flowchart TD
    StartCalc(["Start ProcessCalculation()"]) --> ReadRows[/Read All Input Rows from DOM/]
    ReadRows --> InitFlags["allValid = true
decimalValues = [ ]
originalTokens = [ ]
decimalTokens = [ ]"]

    InitFlags --> PrepLoop{{For i = 1 to TotalRows}}
    PrepLoop --> ReadRowIO[/Read base and rawVal for Row i/]
    ReadRowIO --> CheckEmpty{"rawVal is Empty?"}

    CheckEmpty -->|"Yes"| OutEmptyErr[/Display 'Input cannot be empty'/]
    OutEmptyErr --> ClearMatrix1[/Clear Row i Conversion Matrix/]
    ClearMatrix1 --> FlagInvalid1["allValid = false"]
    FlagInvalid1 --> NextRowStep

    CheckEmpty -->|"No"| CallValidate[["IsValidNumber(rawVal, base)"]]
    CallValidate --> CheckValidResult{"Is Valid?"}

    CheckValidResult -->|"No"| OutCharErr[/Display 'Invalid character' Error/]
    OutCharErr --> ClearMatrix2[/Clear Row i Conversion Matrix/]
    ClearMatrix2 --> FlagInvalid2["allValid = false"]
    FlagInvalid2 --> NextRowStep

    CheckValidResult -->|"Yes"| ClearErrUI["Remove Error Styling on Row i"]
    ClearErrUI --> CallParse[["decVal = ParseToDecimal(rawVal, base)"]]
    CallParse --> AppendDec["Append decVal to decimalValues"]

    AppendDec --> CallFormatBin[["binStr = FormatBase(decVal, 2, 0)"]]
    CallFormatBin --> CallFormatOct[["octStr = FormatBase(decVal, 8, 0)"]]
    CallFormatOct --> CallFormatHex[["hexStr = FormatBase(decVal, 16, 0)"]]
    CallFormatHex --> DisplayRowMatrix[/Output Row i Matrix: BIN, OCT, DEC, HEX/]

    DisplayRowMatrix --> BuildToken["Append (rawVal + Subscript) to originalTokens
Append decVal to decimalTokens"]
    BuildToken --> NextRowStep["Increment i"]
    NextRowStep --> PrepLoop

    PrepLoop -->|"Loop Complete"| CheckAllValid{"allValid == true AND
decimalValues.length == TotalRows?"}
    CheckAllValid -->|"No"| HideResults["Hide Results Section"]
    HideResults --> ExitCalc(["Halt / Return"])

    CheckAllValid -->|"Yes"| InitMath["computedResult = decimalValues[0]
isDivByZero = false
divZeroIndex = null"]
    InitMath --> MathLoop{{For k = 1 to TotalRows - 1}}

    MathLoop --> FetchNext["nextVal = decimalValues[k]"]
    FetchNext --> BranchOp{"currentOperation"}

    BranchOp -->|"+"| DoAdd["computedResult = computedResult + nextVal"] --> NextK["Increment k"]
    BranchOp -->|"-"| DoSub["computedResult = computedResult - nextVal"] --> NextK
    BranchOp -->|"*"| DoMul["computedResult = computedResult * nextVal"] --> NextK
    BranchOp -->|"/"| CheckZero{"nextVal == 0?"}

    CheckZero -->|"Yes"| SetDivZero["isDivByZero = true
divZeroIndex = k + 1"]
    SetDivZero --> BreakLoop["Break Out of Math Loop"]
    CheckZero -->|"No"| DoDiv["computedResult = computedResult / nextVal"] --> NextK
    NextK --> MathLoop

    MathLoop -->|"Math Complete"| CheckDivFlag{"isDivByZero == true?"}
    BreakLoop --> CheckDivFlag

    CheckDivFlag -->|"Yes"| ShowDivZeroErr[/Output 'Division by Zero' Error on Input divZeroIndex/]
    ShowDivZeroErr --> FormatFormulaErr["formula = decimalTokens + ' = Undefined'"]
    FormatFormulaErr --> OutTilesErr[/Display 'Undefined (Div by 0)' on All 4 Final Result Tiles/]

    CheckDivFlag -->|"No"| FormatFormulaNormal["formula = decimalTokens + ' = ' + computedResult"]
    FormatFormulaNormal --> FinalBin[["finalBin = FormatBase(computedResult, 2, 6)"]]
    FinalBin --> FinalOct[["finalOct = FormatBase(computedResult, 8, 6)"]]
    FinalOct --> FinalDec[["finalDec = FormatBase(computedResult, 10, 6)"]]
    FinalDec --> FinalHex[["finalHex = FormatBase(computedResult, 16, 6)"]]
    FinalHex --> OutTilesNormal[/Display finalBin, finalOct, finalDec, finalHex on Result Tiles/]

    OutTilesErr --> DisplayExpr[/Output expressionString to expression-display
Output formula to decimal-formula/]
    OutTilesNormal --> DisplayExpr
    DisplayExpr --> RevealUI["Reveal Results Section & Smooth Scroll"]
    RevealUI --> EndCalc(["End ProcessCalculation()"])

3. Input Validation Subroutine (`IsValidNumber`)

Character compliance checks for Base 2, 8, 10, and 16.

flowchart TD
    StartVal(["Start IsValidNumber(value, base)"]) --> CheckEmpty{"value is Empty or Null?"}
    CheckEmpty -->|"Yes"| RetFalse1(["Return False"])

    CheckEmpty -->|"No"| CheckSign{"First Char == '-'?"}
    CheckSign -->|"Yes"| StripSign["cleanVal = value without '-'"]
    CheckSign -->|"No"| KeepVal["cleanVal = value"]

    StripSign --> CheckCleanEmpty{"cleanVal is Empty?"}
    CheckCleanEmpty -->|"Yes"| RetFalse2(["Return False"])
    CheckCleanEmpty -->|"No"| SwitchBase{"base Radix"}
    KeepVal --> SwitchBase

    SwitchBase -->|"Base 2"| SetBinPattern["Allowed: '0', '1'"]
    SwitchBase -->|"Base 8"| SetOctPattern["Allowed: '0'..'7'"]
    SwitchBase -->|"Base 10"| SetDecPattern["Allowed: '0'..'9'"]
    SwitchBase -->|"Base 16"| SetHexPattern["Allowed: '0'-'9', 'A'-'F', 'a'-'f'"]

    SetBinPattern --> TestChars{{For each char in cleanVal}}
    SetOctPattern --> TestChars
    SetDecPattern --> TestChars
    SetHexPattern --> TestChars

    TestChars --> MatchCheck{"char matches Allowed Pattern?"}
    MatchCheck -->|"No"| RetFalse3(["Return False"])
    MatchCheck -->|"Yes"| NextChar["Next Character"]
    NextChar --> TestChars

    TestChars -->|"All Characters Validated"| RetTrue(["Return True"])

4. Conversion Subroutines (`ParseToDecimal` & `FormatBase`)

Mathematical conversions between arbitrary number systems and decimal.

flowchart TD
    subgraph S1 ["Subroutine: ParseToDecimal(valueStr, base)"]
        StartP(["Start ParseToDecimal"]) --> CheckNeg{"Starts with '-'?"}
        CheckNeg -->|"Yes"| NegTrue["isNeg = true
cleanStr = valueStr without '-'"]
        CheckNeg -->|"No"| NegFalse["isNeg = false
cleanStr = valueStr"]
        NegTrue --> InitP["decimal = 0"]
        NegFalse --> InitP
        InitP --> LoopP{{For each char in cleanStr}}
        LoopP --> CharNum["digit = ConvertCharToNumber(char)"]
        CharNum --> Accum["decimal = (decimal * base) + digit"]
        Accum --> LoopP
        LoopP -->|"Done"| CheckSignApply{"isNeg == true?"}
        CheckSignApply -->|"Yes"| Negate["decimal = -decimal"]
        CheckSignApply -->|"No"| ReturnP(["Return decimal"])
        Negate --> ReturnP
    end

    subgraph S2 ["Subroutine: FormatBase(num, base, precision)"]
        StartF(["Start FormatBase"]) --> CheckSpecial{"Is NaN or Infinite?"}
        CheckSpecial -->|"Yes"| RetSpecial(["Return 'NaN' or 'Infinity'"])
        CheckSpecial -->|"No"| Decomp["isNeg = num < 0
intPart = FLOOR(ABS(num))
fracPart = ABS(num) - intPart"]
        Decomp --> IntConv["intStr = ConvertIntegerBySuccessiveDivision(intPart, base)"]
        IntConv --> CheckFrac{"fracPart == 0 OR precision <= 0?"}
        CheckFrac -->|"Yes"| RetIntOnly(["Return (isNeg ? '-' : '') + intStr"])
        CheckFrac -->|"No"| LoopFrac{{While fracPart > 0 AND count < precision}}
        LoopFrac --> Scale["fracPart = fracPart * base
digit = FLOOR(fracPart)"]
        Scale --> AppendF["fracStr = fracStr + DigitToChar(digit)
fracPart = fracPart - digit
count = count + 1"]
        AppendF --> LoopFrac
        LoopFrac -->|"Done"| RetFull(["Return (isNeg ? '-' : '') + intStr + '.' + fracStr"])
    end

5. Dynamic Row Management & State Preservation (`RenderInputs`)

Retaining existing user values and bases while restructuring dynamic input fields.

flowchart TD
    StartR(["Start RenderInputs(count)"]) --> CheckC{"count < 3 OR isNaN(count)?"}
    CheckC -->|"Yes"| ClampC["count = 3"]
    CheckC -->|"No"| UseC["Use count"]
    ClampC --> HarvestIO
    UseC --> HarvestIO

    HarvestIO[/Read and Save Existing Row Values into existingData[]/]
    HarvestIO --> ClearDOM["Clear inputsContainer.innerHTML"]
    ClearDOM --> LoopR{{For i = 1 to count}}

    LoopR --> CreateRow["Create Row DOM Elements and 4-Base Result Grid"]
    CreateRow --> CheckSaved{"existingData[i-1] exists?"}
    CheckSaved -->|"Yes"| Restore["Restore previous base and value"]
    CheckSaved -->|"No"| SetDefault["Apply Default Base 10"]
    Restore --> AppendDOM["Append Row to inputsContainer"]
    SetDefault --> AppendDOM
    AppendDOM --> LoopR

    LoopR -->|"Done"| HideRes["Hide resultsSection"]
    HideRes --> EndR(["End RenderInputs()"])

6. Complement Computation Flowchart

Computing both (r−1)'s and r's complements for any number system.

flowchart TD
    StartComp(["Start ComputeComplements(value, base, numDigits)"]) --> PadInput["Pad value to numDigits width with leading zeros"]
    PadInput --> CalcMax["maxDigit = base - 1"]

    CalcMax --> DimLoop{{"For each digit i in padded value"}}
    DimLoop --> SubDigit["complementDigit = maxDigit - digit[i]"]
    SubDigit --> AppendDim["Append complementDigit to diminishedResult"]
    AppendDim --> RecordStep["Record step: maxDigit - digit = complementDigit"]
    RecordStep --> NextDim["Increment i"]
    NextDim --> DimLoop

    DimLoop -->|"All digits processed"| DimDone[/"Output: (r-1)'s Complement = diminishedResult"/]

    DimDone --> AddOne["radixResult = diminishedResult + 1 in base r"]
    AddOne --> CarryCheck{{"Process carry propagation"}}
    CarryCheck --> RadDone[/"Output: r's Complement = radixResult"/]

    RadDone --> EndComp(["End ComputeComplements()"])

7. Subtraction via (r−1)'s Complement (End-Around Carry)

Subtraction using diminished radix complement with end-around carry handling.

flowchart TD
    StartSub(["Start SubtractDiminished(A, B, base, n)"]) --> PadAB["Pad A and B to n digits"]
    PadAB --> CompB[["Compute (r-1)'s Complement of B"]]
    CompB --> AddAComp["sum = A + complement(B) in base r"]
    AddAComp --> CheckCarry{"Carry generated?"}

    CheckCarry -->|"Yes Carry = 1"| EAC["End-Around Carry: Remove carry, add 1 to sum"]
    EAC --> PosResult[/"Result = sum + 1, Positive"/]

    CheckCarry -->|"No Carry = 0"| ReComp[["Take (r-1)'s complement of sum"]]
    ReComp --> NegResult[/"Result = neg complement of sum, Negative"/]

    PosResult --> ConvertAll["Convert result to all 4 bases"]
    NegResult --> ConvertAll
    ConvertAll --> EndSub(["End SubtractDiminished()"])

8. Subtraction via r's Complement (Discard Carry)

Subtraction using radix complement with discard-carry handling.

flowchart TD
    StartSubR(["Start SubtractRadix(A, B, base, n)"]) --> PadABR["Pad A and B to n digits"]
    PadABR --> CompBR[["Compute r's Complement of B"]]
    CompBR --> AddACompR["sum = A + complement(B) in base r"]
    AddACompR --> CheckCarryR{"Carry generated?"}

    CheckCarryR -->|"Yes Carry = 1"| DiscardCarry["Discard carry bit"]
    DiscardCarry --> PosResultR[/"Result = sum, Positive"/]

    CheckCarryR -->|"No Carry = 0"| ReCompR[["Take r's complement of sum"]]
    ReCompR --> NegResultR[/"Result = neg complement of sum, Negative"/]

    PosResultR --> ConvertAllR["Convert result to all 4 bases"]
    NegResultR --> ConvertAllR
    ConvertAllR --> EndSubR(["End SubtractRadix()"])
